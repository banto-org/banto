# Evidence First Rule（証拠優先ルール）

これは**返信時だけのルールではなく、作業全般のデフォルト**である。実装・設計・修正・レビューなど*あらゆる作業中*に適用し、情報を明示的に尋ねられたときに限らない。**知識が古い、または欠落している可能性があるとき、知識カットオフ（学習時点の記憶）だけを根拠に行動しない。**記憶している事実（バージョン、API の形状、過去のプロジェクトでの決定、「ベストプラクティス」）に頼ろうとした瞬間が、それに依拠する**前**に下記の順序で検証するタイミングである。

## トリガー（作業途中を含め、いつ発動するか）

作業中、**古い、または欠落している可能性がある**知識に頼ろうとしていると気づいた瞬間——例えば「たしか最新は vX のはず」「この API はこう動くはず」「前に Z と決めたはず」「ここの慣用句は W のはず」——それが起きたら立ち止まり、まず下記の検索順序を実行する。指示を待たない。これがデフォルトの作業姿勢である。

## 検索順序（厳格）

1. **まずローカル store を検索する** — `search` skill（`/search <query>`）を実行する。クエリを段階的に展開し、`{base}/decisions/` と `{base}/docs/`（既存のリサーチもここにある）を grep でスコアリングし、上位ヒットを Read で検証する。過去の決定・過去のリサーチ・プロジェクトの経緯をここでカバーする。
2. **鮮度が重要な領域では web へエスカレーションする** — `search` が確信の持てるヒットを返さず、**かつ**その事実が鮮度に敏感な場合（AI / LLM の挙動、ライブラリ / フレームワークのバージョン、リリースノート、「ベストプラクティス」、トレンド、比較）、`research` skill に委譲する。`research` 自身のステップ 1 は文字通り「`search` skill を実行する」であり（同じ第一関門）、`search` が確信の持てるヒットを返さない場合にのみ web へエスカレーションする。`research-agent` をサブエージェントとして起動し、親セッションのトークンを空けたまま保つ。

鮮度が重要でない、純粋に内部的な問い（「何を決めたか」「なぜこうなっているか」）については、ステップ 1 だけで順序は完結する——web へエスカレーションしない。`search` が何も見つけなければ、その旨を明確に伝える。

`{base}` は SessionStart で注入される ai-context のベースである。仕組み（語彙展開、`Agent(...)` の呼び出し、webread による精読）は各 skill が持つ——このルールが固定するのは順序だけである：まず `search`、次に（鮮度が重要なギャップに限り）`research`。WebFetch は決定論的にブロックされる（`webfetch-deny.sh`）。検証不能な小型モデルの要約を返すためである。WebSearch は URL を*見つける*ぶんには問題ない（`websearch-gate.sh` のソフトなリマインダーが先に `search` を実行するよう促すが、決してブロックはしない——`BANTO_ALLOW_WEBSEARCH=1` で抑制可能）。ただし大規模な調査は research-agent に委ねる。

## 禁止事項

- ❌ 自身の知識カットオフの記憶だけで答える
- ❌ メインの Claude セッションから直接大規模な WebSearch 調査を実行する（research-agent に委譲する）
- ❌ 「一般的にはこう言われている」といった曖昧な根拠で答える
- ❌ 「おそらく」「たぶん」で断定する

## 適用範囲

**適用対象**（明示的に尋ねられた場合・作業途中で浮上した場合の両方）:
- 技術情報に関する問い（「React の最新版は？」）
- ベストプラクティスに関する問い（「〜のベストプラクティスは？」）
- ライブラリ / ツールの比較
- バージョン / リリース情報
- トレンドと最新の動向
- **実装途中での、古い / 欠落した知識への依拠** — 検証していない、記憶している API / バージョンや過去の決定を根拠にコードを書こうとしている状態。それに踏み切る前に検証する（ステップ 1、鮮度が重要ならステップ 2 も）。実装そのものは引き続き `dependencies` ルールが管轄する。

**対象外**:
- 外部や記憶している事実に依拠しない、機械的なファイル編集 / 修正
- 目の前のコードだけで答えられる問い（プロジェクトローカルのコード検索で十分）
- 単純な挨拶や雑談
