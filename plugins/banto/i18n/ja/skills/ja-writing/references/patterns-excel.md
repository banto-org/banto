# Excel に書くときのパターン（1 セル単位）

Excel は文書ではなく表であるため、セル内の日本語は散文と別の規則で書く。
セルの役割を 3 型（ラベル / 値 / 注記）に分け、型ごとの形を守る。

## 3 型の使い分け

ラベル（見出し行・項目名）: 名詞句のみ。句点なし。8 文字以内を目安。
> 良: 「対応状況」「完了予定日」「担当」
> 悪: 「対応の状況について」「いつ完了する予定か」

値（データセル）: 体言止めまたは数値 + 単位。1 セル 1 事実。句点なし。
> 良: 「対応済」「2026-07-15」「3 件」「保留（仕様確認中）」
> 悪: 「対応済みです。」「7 月中旬ごろには完了する見込みとなっています」

注記（備考セル）: 最長 2 文。1 文目に結論、2 文目に条件。句点は文が 2 つのときだけ。
> 良: 「API 側の修正待ち。7/15 リリースに同梱予定」
> 悪: 「こちらについては先方の API 側の修正を待っている状況であり、それが終わり次第…」

## セル内の禁止事項

改行で複数の事実を詰め込まない（事実が 2 つなら列を分ける）。「〜です・ます」を使わない。
経緯メタ情報（「（最新）」「（修正済）」「※以前は A だった」）を書かない — 版の管理はファイル名と
更新日列が持つ。記号の自作凡例（「◎○△×」）は必ず凡例セルを添え、色だけに意味を持たせない。

## 状態の語彙を固定する

同じ列の状態語は 1 セットに固定し、揺らさない。
推奨セット:「未着手 / 対応中 / 対応済 / 保留 / 対象外」。
「済」「完了」「done」「対応した」を同じ列に混在させない。

## 数値・日付

数値は数値型で入れ、単位は列見出しへ（「金額（万円）」）。セル内に「約」を書かない —
概算なら注記列に根拠を書く。日付は yyyy-mm-dd に統一。「7 月中」「近日」を値セルに書かない
（確定しない日付は「未定」+ 注記）。

## 1 枚に収める設計

シートの目的を 1 つに絞り、読む順（左 → 右が時系列・上 → 下が優先度）を崩さない。
列が 12 を超えたら別シートへ分割を検討。フィルタ・並べ替えを壊すセル結合を使わない。
