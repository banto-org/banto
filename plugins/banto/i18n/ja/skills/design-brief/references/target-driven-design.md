# ターゲット駆動デザイン — なぜターゲットを最初に固定するか

同じサービスでも、ターゲットが変わればデザインの正解が変わる。色・文字サイズ・トーン・
ビジュアルスタイルはすべてターゲットから波及して決まるため、ブリーフの②ターゲットが
埋まらないうちは③以降へ進まない。

## ターゲットの書き方

年齢や性別だけでは不十分。次の 3 要素をセットで書く。

- 人物像：年齢層、職業、IT の習熟度など
- 状況：いまどんな場面でこのサービスに触れるか
- 感情：その状況で何を感じ、何を求めているか

「30 代女性」だけでは何も決まらない。「30 代前半のフリーランス。締切に追われて時間がなく、
難しい操作より安心感のある簡潔な UI を求めている」まで書いて初めて、色や文字サイズの判断
材料になる。

## 実例：同一サービスでターゲットが 3 通りの場合

語学学習アプリを例に、ターゲットごとにデザインの正解がどう変わるかを示す。

| 観点 | 高齢者向け | 20 代女性向け | 法人研修担当者向け |
|---|---|---|---|
| 色 | コントラストを強め、落ち着いたネイビー基調 | 温かみのあるコーラルピンク、柔らかい配色 | 白背景にネイビー・ブルーの信頼感重視配色 |
| 文字サイズ | 本文 18px 以上、太めの書体 | 本文 16px、丸みのある書体で親しみやすく | 本文 15〜16px、可読性重視のゴシック体 |
| トーン | わかりやすさ・安心感を最優先 | 親しみやすさ・気分転換の楽しさ | 効率性・成果の見える化を重視 |
| スタイル | フラットデザイン中心、装飾を最小限に | クレイモーフィズム × ポップ寄り | コーポレート × ダッシュボード UI |
| 避けたい印象 | 情報過多、操作の複雑さ | 事務的、味気ない印象 | カジュアルすぎる印象、遊び心の出しすぎ |

同じ「語学学習」でも、高齢者向けは操作の迷いをなくす方向、20 代女性向けは楽しさを伝える
方向、法人研修担当者向けは成果と信頼を伝える方向へ、正解が明確に分かれる。

## ターゲットから各観点への波及

ターゲットを固定したら、次の対応で各観点へ波及させる。

- 年齢層が高く IT の習熟度が低い → 文字サイズを大きく、操作をシンプルに、コントラストを
  強める
- 若年層・柔らかい印象を求める → 丸みのある書体、パステル寄りの配色、クレイモーフィズムや
  Kawaii 系のスタイル
- 法人・意思決定者 → 信頼感を重視した配色（ネイビー・ブルー系）、データや実績を見せる
  ダッシュボード寄りのレイアウト

## 避けたい印象は必ず併記する

希望する印象だけを伝えると、AI やデザイナーは無難な方向に寄せがちになる。「モダンにして
ほしいが、冷たい印象は避けたい」のように、対で伝えると精度が上がる。

## 受け手レベルとの関係

banto の `skills/ja-writing/references/audience-levels.md` が扱う受け手レベル（L1-L3）は文章の
読みやすさを決める軸、本ファイルが扱うターゲットは画面の見た目を決める軸で、互いに独立して
指定する。
