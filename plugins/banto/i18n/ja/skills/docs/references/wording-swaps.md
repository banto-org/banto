# wording-swaps ― 硬い表現の言い換え正典（機械検出: scripts/style-sweep.py）

一般のビジネス文書で「硬い・翻訳調・冗長」と受け取られる表現と、その置き換え先。
JTF 系スタイルガイド・textlint 公式ルール（ja-no-redundant-expression 等）・編集実務コラムが
一致して指摘するパターンを収録した。根拠の詳細は
`{base}/docs/research/2026-07-20_stiff-japanese-rewrite-table.md`。

運用: 執筆後に `scripts/style-sweep.py` を実行 → 検出行を 1 つずつ判定 → 言い換えるか、
意図的に残す場合は除外リストに登録（判定の記録になる）→ 再実行で検出ゼロにする。

## 1. 言い換え表（最頻出。✗ 問題 → ✓ 修正）

| ✗ 硬い・冗長 | ✓ 言い換え | 注意 |
|---|---|---|
| 〜することができる | 〜できる | 最頻出の冗長。可能形単独で足りる |
| 〜することが可能である | 〜できる | 同上。名詞述語化でさらに硬い |
| 〜されうる／〜し得る | 〜される可能性がある／〜されることがある | 一般文書では「され得る」は硬く響く |
| 〜たりうる | 〜になりうる／〜となる可能性がある | 文語語尾を開く |
| （サ変名詞）を行う | （サ変名詞）する（調査を行う→調査する） | 「処理を行う」「カタカナ語＋を行う」は許容 |
| （サ変名詞）を実行する | （サ変名詞）する | 同上 |
| 〜において | で／では | 改まった文脈以外では「で」 |
| 〜に関して | 〜について | 「に関して」の方が硬い |
| 〜に基づき | 〜をもとに／〜に沿って | 法令調が不要なら開く |
| しかしながら | しかし | 冗長な逆接 |
| 一面においては | 一方で | 文語的前置き |
| その結果として | その結果 | 「として」は不要 |
| であると言えます | である／と言えます（片方だけ） | 断定機能の二重化 |
| であると考えている | である／と考えている（片方だけ） | 同上 |
| であろう | 〜と推測される／だろう | 文語の助動詞を開く |
| 〜であるところの | （削って直接係らせる） | 現代の一般文書では使わない |
| 一番最初／まず最初 | 最初（に） | 二重表現 |
| 〜のではないか | 〜ではないか | 意味のない「の」 |
| 完全に／非常に／極めて | （原則削除） | 根拠なき強調は空語。数値で置き換える |
| 重要なのは〜である／まとめると | （予告せず中身を書く） | LLM 特有の予告・総括系 |
| 〜と言えるだろう | 言い切る／〜と考えられる | 根拠なき緩和は主張を弱める |

「〜に対して」は話題でなく対象・向き先を示す機能語なので、硬さだけで一律置換しない（意味が変わる）。

## 2. モダリティ確度表（断定を避ける表現の使い分け）

軸は「硬い/柔らかい」ではなく**確度**と**ネガポジ**。一律に「かもしれない」へ寄せると意味が変わる。

| 表現 | 確度 | ネガポジ | 使う場面 |
|---|---|---|---|
| 断定（〜だ・〜である） | 確定事実 | 中立 | 事実の直接記述。根拠が明確なら言い切る |
| 〜と考えられる | 高（データ・分析に基づく） | 中立 | 論理的推論。「思われる」より客観的 |
| 〜とみなされる | 高（規定・基準の適用） | 中立〜ネガ | 規定・契約・法の判定のみ。私見には使わない |
| 〜可能性がある | 中（幅が広い） | **両用（中立）** | 客観予測の既定。フォーマル文書の第一候補 |
| 〜見込みだ | 中〜高（根拠ある前向き予測) | ポジ寄り | 業績・計画の見通し |
| 〜おそれがある | 高低を問わない | **ネガ専用** | リスク警告・注意喚起のみ |
| 〜場合がある | 条件付き発生 | 中立 | マニュアル・規約（発生条件を必ず添える） |
| 〜と思われる | 低〜中（印象ベース） | 中立 | 控えめな私見。報告書では「考えられる」を優先 |
| 〜かもしれない | 低（主観） | 中立 | 会話向け。報告書・提案書では避ける |

## 3. 判定のコツ

- 検出された語が**改まった通知・契約・法令調の文脈**なら残してよい（「〜により」等）。除外リストに登録して理由を残す
- 言い換えで**意味（確度・対象・拘束力）が変わる**ときは、表 2 で同じ確度・同じネガポジの表現を選ぶ
- 迷ったら音読する。口に出して不自然な語は書き言葉でも硬い
