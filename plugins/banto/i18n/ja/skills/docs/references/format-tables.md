# format-tables ― 表の使い方（全形式共通）

## 表にすべきか、まず判断

| 情報 | 使う形式 |
|---|---|
| 個々の値を正確に見せる・引かせる | 表 |
| 傾向・パターン・比較の大小を見せる | グラフ（棒・折れ線） |
| 因果・理由・物語 | 文章 |

3件以上の項目×2属性以上なら文章でなく表。表かグラフか迷ったら「読者は個々の数値を読むか？」で決める（Yes=表）。

## 設計ルール（Stephen Few系の実証原則）

1. **罫線は最小限**: 縦罫線は原則なし。横罫線もヘッダー下と合計上程度。区切りは余白で作る
2. **数値は右揃え**・桁区切りあり・**単位は列見出しに**（セルには数値のみ）。同一列の小数桁を統一
3. **有効桁数を絞る**: 比較に必要な桁だけ（目安2〜3桁）。精密値は付録へ
4. **比較したい値は縦に並べる**: 読者が比べる数値が同じ列に縦に並ぶ配置にする
5. **列順は重要度順**: 最重要の列を左に。行は論理順（大きい順・時系列・五十音）
6. **合計行は最下部**（会計慣行）。強調は太字1属性のみ
7. **ゼブラストライプ（縞背景）は慎重に**: 行が多く横に長い表のみ。使うなら極薄いコントラストで
8. **ヘッダーは短く**: 2行に折り返すくらいなら語を削る。グループ化ヘッダーは1階層まで

## 強調

色だけに頼らない（色覚・印刷対応）。太字・記号（▲▼）・注記を併用する。
強調は1表につき1種類。全部強調は無強調と同じ。

## 注記・脚注

出典・前提・例外はテーブル直下に小さく。セル内に長文を書かない。

## 形式別の実装

- **HTML**: `<th scope="col">`/`<th scope="row">`を必ず付ける（スクリーンリーダー対応）。キャプションは`<caption>`か直前の見出し
- **xlsx**: セル結合禁止。1セル1データ。フィルタを付けて渡す
- **pptx**: 1スライドの表は最大5行×4列程度。それ以上は配布資料（xlsx/docx）に分離
- **docx**: 表番号（表1）＋タイトルを**表の上**に置く（図は下、表は上の慣行）
