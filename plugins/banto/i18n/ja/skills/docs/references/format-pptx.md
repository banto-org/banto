# format-pptx ― スライド資料

最初に用途を確認する。**投影用**（プレゼンで話す）か**配布用**（読む資料・コンサル型）かで設計が変わる。

## 共通ルール

1. **1スライド1メッセージ**。詰め込むならスライドを分ける
2. **見出しはメッセージ文にする**（writing-core ルール 18 の全形式共通則。スライドでは必須）: 本文・図はその見出しの証拠として置く
3. 表紙→エグゼクティブサマリー（結論1枚）→本文→まとめ、の順。10枚を超えるなら章区切りスライド
4. フォントはテーマ指定（既定: Noto Sans JP系）。**本文18pt以上**、タイトル28pt以上、欄外注12pt
5. コントラスト4.5:1以上（投影時は色が2〜3割薄く見える前提で濃いめに）

## 投影用と配布用の違い

| | 投影用 | 配布用（読む資料） |
|---|---|---|
| 文字量 | 最小限（話者が補う） | 自己完結（読んで分かる） |
| 1枚の情報量 | 少（図1つ＋メッセージ） | 多（見出し文＋根拠＋注記） |
| 欄外注・出典 | 最小限 | しっかり付ける |

## 図（SVG→PNG変換。必須手順）

pptxはSVGを確実に扱えないため、**必ずPNGに変換してから挿入**する:

1. SVGを作る（diagram skill のパターン、テーマの色）
2. PNG変換: `rsvg-convert -w 2400 -b none figure.svg -o figure.png`（幅2400px≒300dpi相当、`-b none`で透過）。rsvg-convertがなければ `inkscape --export-type=png --export-width=2400`、それもなければplaywright/chromiumでスクリーンショット
3. python-pptxで挿入し、スライド幅に対して適切なサイズを指定

## 表示チェック（必須。スキップ禁止）

生成したpptxは必ずレンダリングして目で確認する:

1. `libreoffice --headless --convert-to pdf 生成物.pptx` でPDF化し、pdftoppm等で各ページをPNG化
2. 各スライド画像を開いて確認: (a)文字のはみ出し・折り返し崩れ (b)図の欠け・にじみ・縦横比崩れ (c)ラベルの重なり (d)フォント置換による崩れ
3. 崩れがあれば修正して再変換・再確認。確認せずに納品しない
4. ツール不在時のフォールバック: libreofficeが無ければ、python-pptxで読み戻して図サイズ・テキスト溢れを数値検査し、変換前PNGを単体で目視確認。レンダリング確認ができなかった旨を必ず報告に明記する

## 用語注釈

初出スライドの下部に欄外注（12pt、ink-soft色）。頻出語は末尾に「用語」スライドを1枚。

## 出典

外部情報はスライド下部に小さく出典を記載。全出典を末尾スライドにまとめてもよいが、数値の出典はそのスライドに置く。
