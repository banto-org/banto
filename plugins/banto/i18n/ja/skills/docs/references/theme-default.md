# theme-default ― 既定テーマ（日本ビジネス標準・差し替え可能）

> **差し替え方法**: このファイルと同じ形式で、同じ references/ フォルダに `theme-custom.md` を作ると、そちらが優先される。
> 会社のブランドカラーや個人の好みは theme-custom.md に書く。このファイルは編集しない。

設計方針: ベースはアイボリー地 + 白カード、メインは紺（青系）。「紺をメインに据える」構成は日本のビジネス資料で信頼感の定番とされる配色
（MiriCanvas / Document Studio）。配分は 70:25:5（ベース:メイン:アクセント）。ステータス色は
カラーユニバーサルデザイン（CUD）推奨配色セット第 3 版の実値を使い、文字に使う色はすべて
WCAG コントラスト比を算出済みの組み合わせに限定する。

## ステータス色（CUD 準拠・用途で 3 系統に分ける）

色だけに頼らない: アイコン（✓ ✗ ⚠）・ラベル文言・枠線を必ず併用する（CUD の鉄則）。

| ステータス | ①小さい文字用（濃色） | ②アイコン・大文字・図形用（CUD アクセント） | ③淡地（バッジ・塗り分け、CUD ベース） | ④カード淡地（大面積・派生） |
|---|---|---|---|---|
| 成功・良い例 | `#1D7A4E`（5.32:1、アイボリー地 4.98:1） | `#35A16B` | `#87E7B0`（紺文字 8.63:1） | `#E9F6EF` |
| 問題・悪い例 | `#B32800`（6.52:1） | `#FF2800` | `#FFD1D1`（紺文字 9.37:1） | `#FFEFEF` |
| 警告・注意 | `#8F4F00`（6.39:1） | `#FF9900` | `#FFFF99`（紺文字 12.26:1） | `#FFF6E5` |
| 情報 | `#0B3E8D`（10.06:1） | `#0041FF` | `#B4EBFA`（紺文字 9.93:1） | `#EFF7FB` |

- ②の CUD アクセント色は白地上で 4.5:1 未満のため**小さい文字には使わない**（緑 3.25 / 赤 3.78 / 黄 1.16）
- ①はデジタル庁方式（ブランド色が基準を満たさない場合、同色相で明度調整）で導出した文字用の濃色
- ④は①③と同色相の派生淡地（黒文字で 11.3:1 以上）。色数を増やさず明度違いで対応する原則（Document Studio）

原則: 意味と色を固定する（成功=緑系、問題=赤系を入れ替えない）。1 資料に使う色は紺系 + ステータス系
+ 無彩色の範囲に収め、新しい色相を足さない。強調は色以外の属性（太字・アイコン）を併用する。

## 形式別の対応値

- **HTML**: 上記トークンを CSS 変数（--bg, --accent 等）にそのまま割り当てる
- **pptx**: accent=RGB(17,49,96)、accent-2=RGB(255,153,0)（図形・帯のみ）。タイトル 28pt〜/本文 18pt〜/欄外注 12pt。投影時は淡地②③を使い分け、文字は紺か黒
- **docx**: 見出し 1=accent 色 16pt 太字、見出し 2=14pt 太字、本文黒（#000000）。行間 1.3
- **xlsx**: ヘッダー行=accent 地 `#113160` に白文字（12.87:1）、入力セル=青文字 `#0B3E8D`、計算セル=黒文字、他シート参照=緑文字 `#1D7A4E`（financial modeling 慣行 + 文字用濃色）

## 図（SVG）の色

diagram skill で作る図のカラートークンはこの表と同一に保つ（正解・対策=緑系①④、問題=赤系①④、
主役・流れ=紺、強調=オレンジ②を小面積のみ）。theme-custom.md を作る場合は図の色も併せて定義すること。
