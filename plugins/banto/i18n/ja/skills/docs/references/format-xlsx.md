# format-xlsx ― Excel資料

数値を確認・再利用・並べ替えるための形式。「読む資料」はHTMLかdocxで作り、Excelを文書レイアウトに使わない。

## シート構成

1. **1シート1目的**。先頭に「表紙/README」シート（目的・シート一覧・凡例・更新日・作成者）
2. シート名は内容が分かる日本語で短く。並び順は読み手の作業順
3. 大きなデータは「データ」シートと「集計/見せる」シートを分ける

## レイアウト

- **A1から始めない**: A列と1行目を空けてB2起点（余白が枠になる）
- ウィンドウ枠の固定（ヘッダー行・キー列）を必ず設定
- グリッド線は非表示にし、必要な罫線だけ引く
- 列幅は内容に合わせ、ヘッダー行はテーマのaccent地＋白文字

## 色の規約（financial modeling慣行）

| 色 | 意味 |
|---|---|
| 青文字 | 手入力値（ハードコード） |
| 黒文字 | 同一シート内の計算式 |
| 緑文字 | 他シート参照 |
| 赤文字 | 外部リンク・要注意 |

この規約は理由ごと表紙シートの凡例に書く（読者が規約を知らない前提）。

## 数値書式

- 表示のみ丸める（実値を変えない）: 千円単位`#,##0,`、百万円単位`#,##0,,`
- 負数は会計形式のかっこ書き `(1,234)`、日付はISO形式（YYYY-MM-DD）で統一
- パーセントは小数1桁まで

## 神Excel（方眼紙Excel）の禁止

セル結合禁止・1セル1データ・改行やスペースでの位置調整禁止（総務省「機械判読可能なデータの表記方法」準拠）。
印刷前提の場合も、結合ではなく「選択範囲内で中央」を使う。

## 図

SVGは**PNGに変換して挿入**（300dpi相当・透過。変換は format-pptx.md と同じ手順）。挿入後にセルとの重なり・拡縮の崩れを確認。

## 用語注釈

専門語には注記列かセルコメント。頻出語は「用語」シートにまとめ、表紙から言及する。

## 納品前チェックリスト

1. 全シートでA1セルを選択した状態で保存（開いたとき先頭が見える）
2. 先頭シート（表紙）を表示した状態で保存
3. ズーム100%に統一
4. 印刷範囲とページ設定（印刷可能性がある場合）
5. 数式エラー（#REF!等）ゼロ、外部リンク切れゼロ
6. openpyxlで生成した場合は実際にExcel/LibreOfficeで開いて表示確認。開けない環境ではopenpyxlで読み戻して値・書式・数式エラーを機械検査し、表示確認ができなかった旨を報告に明記
