# 共感ゲート + 倫理境界

CONCEPT.md を確定する前に、思想が**共感を生むか**と**倫理を越えていないか**を必ずチェックする。

## 共感ゲート（7 項目）

Phase 6 で CONCEPT.md に対して確認。1 つでも明確に NG なら該当 Phase に戻る。

1. **主人公テスト**（StoryBrand）: 物語の主人公は**顧客**か？（製品/企業が主役になっていないか。ブランドはガイド役）
2. **アイデンティティ共鳴**（Oyserman の Identity-Based Motivation）: Tribe が「**これは自分のことだ**」と感じるアイデンティティに触れているか
3. **SUCCESs**（Made to Stick）: Simple / Unexpected / Concrete / Credible / Emotional / Story のうち最低 3 つを満たすか
4. **ethos / pathos / logos バランス**（Aristotle）: 信頼(ethos)が土台にあり、感情(pathos)で動かし、論理(logos)で正当化できているか
5. **Narrative Transportation**: 思想が**物語**として没入させられるか（箇条書きの機能列挙で終わっていないか）
6. **Stickiness テスト**: 北極星と WHY を **10 語以内**で言えるか（言えないなら尖っていない）
7. **倫理テスト（TARES）**: 下記 5 基準を満たすか

## TARES テスト（倫理の 5 基準）

思想・メッセージが以下を満たすこと:
- **T**ruthful（真実か）
- **A**uthentic（本物の確信に根ざすか）
- **R**espectful（相手を尊重しているか）
- **E**quity（公正か・情報の非対称を悪用しないか）
- **S**ocial responsibility（社会的責任を果たすか）

## 禁止（ダークパターン）

共感の「**操作（manipulation）**」と「**正当な共鳴（authentic resonance）**」の線を越えない:
- 偽の希少性・偽の社会的証明（fake urgency / fake reviews）
- 恐怖・不安の煽動で判断を奪う
- 解約困難・confirmshaming（「いいえ、私は成功したくありません」式）
- パラソーシャル関係の搾取（依存を意図的に作る）
- 持っていない思想・実績を装う

## 線引きの原則

| 正当な共鳴 | 操作 |
|---|---|
| 本物の確信を明確に伝える | 確信を装う／捏造する |
| 相手が自分で選べる情報を出す | 選択を奪う・急かす |
| 価値観に正直に呼びかける | 不安・恐怖を人工的に作る |
| 「合わない人は去ってよい」 | 全員を逃さない設計 |

**skill の鉄則**: 思想の**起源は人間**。AI は引き出して尖らせ、倫理ゲートで守る。**AI が共感を捏造しない。**
