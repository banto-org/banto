# 思想形成・問いの台本（Phase 1-6）

各 Phase で**テキストで**問う（SKILL.md の対話フロー方針を参照）。一度に全部投げず、相手の答えを受けて深掘りする。誘導せず、相手の生の言葉を拾う。

## Phase 1: 第一原理で「なぜ」を掘る

ソクラテス式 6 段階（明確化→仮定挑戦→証拠→代替視点→結果→メタ）+ 5 Whys。

- なぜこの製品/サービスが**存在すべき**なのか？（「儲かるから」は禁止、その下を掘る）
- この業界で「**当然」とされている前提**を 3 つ挙げて。それは物理法則か、ただの共有された信念か？
- これが**この世に無かったら**、誰の何が困る？
- あなたが**本当に許せない**現状は何？（怒りは思想の種）
- （5 Whys）「なぜ？」を 5 回繰り返して、これ以上掘れない一文に到達する

→ 出力: **WHY の核（1-2 文）**

## Phase 2: アーキタイプ同定

詳細は [`archetypes.md`](archetypes.md)。

- あなたが製品/世界を語る時、**繰り返し出てくる言葉**は？（採取して提示）
- 次のどれに一番反応する？: 真実を知る(Sage) / 美しく創る(Creator) / 困難を超える(Hero) / 秩序を破る(Outlaw) / 不可能を実現(Magician) / 未踏を行く(Explorer) / 標準を作る(Ruler) / 守る(Caregiver)
- 尊敬する企業/人を 3 つ。その共通点は？（ドミナント型のヒント）

→ 出力: **ドミナント型 + セカンダリー型 + その型が示す思想の方向**

## Phase 3: 反NG宣言

- **10 年後、どうなっていたら「魂を売った」と後悔する？**
- 投資家/上司に「**これをやれば確実に売れる**」と言われても、思想に反するから**絶対やらない**ことは？
- 競合が全員やっているが、あなたは**意地でもやらない**ことは？
- 「カームな働き方」を守るため大企業向け化を拒んだ Basecamp のように、**何を守るために何を捨てる**？

→ 出力: **反NG宣言 3-5 個**（「やること」より強く思想を語る）

## Phase 4: 美的シグナル

- あなたの製品が部屋にあったら、**何も言わずに何を主張する**？
- モノトーンかカラフルか、沈黙か饒舌か、それぞれの選択で**何を宣言したい**？
- 触り心地・トーンを **1 語**で言うと？その理由は？

→ 出力: **感触・トーン 1 語 + 理由**（[`archetypes.md`](archetypes.md) の符号化表を参照）

## Phase 5: 遡及的一貫性 + Tribe

遡及的一貫性（過去の蓄積を一貫した物語に編む。sensemaking であって欺瞞ではない）:
- これまでのピボット/失敗を、**一貫した一つの探索**として語り直すと？
- 「最初からこれを目指していた」と言える**通底する一本の線**は？

Tribe（価値観クラスタで定義）:
- これに「**自分のことだ**」と感じるのは、どんな**価値観**を持つ人？（年齢/性別でなく信念で）
- その人が、あなたの製品に出会って「**やっと分かってもらえた**」と泣くとしたら、何に対して？

→ 出力: **一貫した物語 1 段落 + Tribe 定義**

## Phase 6: 結晶化

1. 上記を **5 要素 CONCEPT.md**（WHY / 反NG / Tribe / Aesthetic Signal / 北極星）に落とす
2. **北極星**（質的）を確定: 「**誰が、どんな状態になったら**成功か」（数値はその後）
3. [`empathy-and-ethics.md`](empathy-and-ethics.md) の**共感ゲート 7 項目**でチェック → 通らなければ該当 Phase へ戻る
4. **採用解釈レポート**として提示し、ユーザーが確定 → 保存 + CLAUDE.md @import

## 軽量モード（実験向け）の最小問い

- **何の信念/仮説を試している？**（1 行）
- **成功＝どうなったら？**（1 行）

この 2 行だけ CONCEPT.md に書き、本番化が決まったらフルへ昇格。
