# 12 ブランドアーキタイプ + 創業者写像 + 美的シグナル

系譜: Jung（集合的無意識）→ Campbell（英雄の旅）→ Pearson（12 発達段階）→ Mark & Pearson『The Hero and the Outlaw』(2001)

## 12 アーキタイプ早見

| 型 | 核の欲求 | 思想の方向 | 代表 |
|---|---|---|---|
| **Sage（賢者）** | 真実・理解 | データ・知・正確さ | Google, Bezos(データ) |
| **Creator（創造者）** | 創る・表現 | デザイン・美・オリジナリティ | Jobs(デザイン), Lego, Adobe |
| **Hero（英雄）** | 勇気・達成 | 困難を乗り越える・実行力 | Nike, SpaceX |
| **Outlaw（無法者）** | 解放・破壊 | 既存秩序への反逆 | Harley, 初期 Tesla |
| **Magician（魔術師）** | 変容・実現 | 不可能を可能に・体験の魔法 | Apple(体験), Disney |
| **Explorer（探検者）** | 自由・発見 | 未踏・未来・冒険 | Musk(未来), Patagonia, Jeep |
| **Ruler（支配者）** | 統制・秩序 | 標準・信頼・プラットフォーム | Amazon(統制), Microsoft |
| **Caregiver（守護者）** | 保護・奉仕 | 安全・思いやり・守る | Anthropic(安全), Volvo |
| **Innocent（無垢）** | 安心・幸福 | シンプル・誠実・楽観 | Coca-Cola, Dove |
| **Everyman（庶民）** | 所属・つながり | 親しみ・等身大・包摂 | IKEA, Target |
| **Lover（恋人）** | 親密・官能 | 美・関係・情熱 | 化粧品・高級ブランド |
| **Jester（道化）** | 楽しさ・今 | ユーモア・遊び・軽さ | 一部 D2C, ゲーム |

**テックスタートアップ頻出 5 型**: Sage / Creator / Hero / Explorer / Ruler。

## 創業者 → 思想の結晶化パターン（事例）

| 創業者 | 自然な傾向 | ドミナント型 | 制度化された形 |
|---|---|---|---|
| Bezos | 顧客中心・データ | Sage + Ruler | Day 1 Culture / PR-FAQ / 16 Leadership Principles |
| Jobs | 禅 × 包括美学・摩擦の除去 | Creator + Magician | Ive との 20 年協働・デザイン言語 |
| Musk | 第一原理・物理制約のみ | Explorer + Hero | コスト=物理制約・ロケット材料費 2% の発見 |
| Dario(Anthropic) | 安全=自由の前提 | Sage + Caregiver | Constitutional AI / Long-Term Benefit Trust |
| Jason Fried | カームな抵抗 | Outlaw + Everyman | Rework / Shape Up / Do not grow・scale・exit |

> Claremont McKenna 研究の示唆: **創業者の自然な傾向はブランドブックより強く、18 ヶ月以内に製品 DNA に浸透する**。だから「型に合わせる」のでなく「**自然な傾向を採取して型で尖らせる**」。

## 写像の手順（Phase 2 で使う）

1. **自然語の採取**: 相手が製品/世界を語る時に繰り返す言葉・比喩・怒りどころを拾う（誘導しない）
2. **ドミナント 1 型を特定**（70-80%）: どの「核の欲求」に一番反応するか
3. **セカンダリー 1 型**: 補助的に出る型
4. **全接点で一致テスト**: その型で UI・コピー・価格・サポートまで一貫させられるか
5. 迷ったら 2 型を提示し、相手の「しっくり来る」で決める（採用解釈で断定しすぎない）

## 美的シグナル（Aesthetic Signal）— 記号論

Barthes の 4 層（外延→内包→神話→イデオロギー）。デザイン選択は思想の宣言:

| 選択 | 符号化される思想 |
|---|---|
| モノトーン / 余白多 | 誠実さ・自信・「足し算をしない」 |
| カラフル / 密度高 | 親しみ・エネルギー・包摂 |
| 内部構造の露出（Dyson） | 透明性・誠実さ・技術への誇り |
| Serif | 権威・伝統への帰属 |
| Sans-serif | 先入観の拒否・現代性 |
| ベゼルレス / シームレス | 「技術が透明になる」世界観の自然化 |
| 手描き / 不均一 | 人間性・反・量産 |

**問い**: 「あなたの製品が部屋にあったら、何も言わずに何を主張する？」→ それが美的シグナル。
