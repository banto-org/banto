# 12 Brand Archetypes + Founder Mapping + Aesthetic Signal

Lineage: Jung (collective unconscious) → Campbell (the hero's journey) → Pearson (12 stages of development) → Mark & Pearson, *The Hero and the Outlaw* (2001)

## 12 archetypes at a glance

| Type | Core desire | Ideological direction | Representatives |
|---|---|---|---|
| **Sage** | Truth / understanding | Data / knowledge / accuracy | Google, Bezos (data) |
| **Creator** | Create / express | Design / beauty / originality | Jobs (design), Lego, Adobe |
| **Hero** | Courage / achievement | Overcoming hardship / execution | Nike, SpaceX |
| **Outlaw** | Liberation / disruption | Rebellion against the established order | Harley, early Tesla |
| **Magician** | Transformation / realization | Making the impossible possible / the magic of experience | Apple (experience), Disney |
| **Explorer** | Freedom / discovery | The unexplored / the future / adventure | Musk (future), Patagonia, Jeep |
| **Ruler** | Control / order | Standards / trust / platform | Amazon (control), Microsoft |
| **Caregiver** | Protection / service | Safety / care / protection | Anthropic (safety), Volvo |
| **Innocent** | Reassurance / happiness | Simplicity / sincerity / optimism | Coca-Cola, Dove |
| **Everyman** | Belonging / connection | Familiarity / down-to-earth / inclusion | IKEA, Target |
| **Lover** | Intimacy / sensuality | Beauty / relationships / passion | Cosmetics / luxury brands |
| **Jester** | Fun / the present | Humor / play / lightness | Some D2C, games |

**The 5 types frequent among tech startups**: Sage / Creator / Hero / Explorer / Ruler.

## Founder → ideology crystallization patterns (cases)

| Founder | Natural tendency | Dominant type | Institutionalized form |
|---|---|---|---|
| Bezos | Customer-centric / data | Sage + Ruler | Day 1 Culture / PR-FAQ / 16 Leadership Principles |
| Jobs | Zen × comprehensive aesthetics / removing friction | Creator + Magician | 20-year collaboration with Ive / design language |
| Musk | First principles / physical constraints only | Explorer + Hero | Cost = physical constraint / the discovery that rocket material cost is 2% |
| Dario (Anthropic) | Safety = the premise of freedom | Sage + Caregiver | Constitutional AI / Long-Term Benefit Trust |
| Jason Fried | Calm resistance | Outlaw + Everyman | Rework / Shape Up / Do not grow・scale・exit |

> Insight from Claremont McKenna research: **a founder's natural tendency is stronger than the brand book and permeates the product DNA within 18 months**. So rather than "conforming to a type", **collect the natural tendency and sharpen it with the type**.

## Mapping procedure (used in Phase 2)

1. **Collect natural language**: pick up the words, metaphors, and pain points the person repeats when describing the product/world (do not lead them)
2. **Identify one dominant type** (70-80%): which "core desire" do they respond to most
3. **One secondary type**: the type that appears as support
4. **Consistency test across all touchpoints**: can you keep that type consistent through UI, copy, pricing, and support
5. If unsure, present two types and let the person decide by what "feels right" (do not over-assert with an adopted interpretation)

## Aesthetic Signal — semiotics

Barthes' 4 layers (denotation → connotation → myth → ideology). A design choice is a declaration of ideology:

| Choice | Encoded ideology |
|---|---|
| Monochrome / lots of whitespace | Sincerity / confidence / "no addition" |
| Colorful / high density | Familiarity / energy / inclusion |
| Exposed internal structure (Dyson) | Transparency / sincerity / pride in technology |
| Serif | Authority / belonging to tradition |
| Sans-serif | Rejection of preconceptions / modernity |
| Bezel-less / seamless | Naturalizing the worldview that "technology becomes transparent" |
| Hand-drawn / uneven | Humanity / anti-mass-production |

**The question**: "If your product were sitting in a room, what would it assert without saying a word?" → that is the aesthetic signal.
