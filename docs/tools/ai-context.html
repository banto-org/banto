Knowledge & context知識 & コンテキスト

ai-context — decisions · memos · knowledge · storeai-context — 決定 · メモ · 知識 · ストア

The persistent memory layer behind Banto's self-driving loop: decision logs, checkpoints, the task file, document sorting, memos, and knowledge promotion, all under one router. Internal search over what's already stored belongs to the sibling search skill, not this one.

自走ループを支える永続記憶層。決定ログ・チェックポイント・タスクファイル・ドキュメント振り分け・メモ・ナレッジ昇格を、ひとつのルーターの下でまとめる。すでに格納済みの内容を探すのは兄弟 skill の search の役目で、ai-context ではない。

01

What it does何をするか

Subcommand router. The first token of the argument selects a procedure: bootstrap / local / doctor / sort / next / phase-done / ignore / tasks split / migrate / memo / knowledge / ref. Twelve subcommands, one entry point.

サブコマンドルーター。引数の最初のトークンで手順が決まる：bootstrap / local / doctor / sort / next / phase-done / ignore / tasks split / migrate / memo / knowledge / ref。12 個のサブコマンドを 1 つの入口で受ける。

Writes go under the ai-context base — the absolute path injected at SessionStart, either a central store or a provisional local (ai-context-local/<project>). bootstrap promotes the provisional local into a real GitHub-backed store; local pins a repo to stay local-only.

書き込み先は ai-context ベース — SessionStart が注入する絶対パスで、中央 store か仮ローカル（ai-context-local/<project>）のいずれか。bootstrap は仮ローカルを実 store へ後追い移行し、local はリポジトリをローカル限定に固定する。

02

When it firesいつ動くか

Fires on decision/task/memo/knowledge language, or explicit subcommands.

決定・タスク・メモ・ナレッジ関連の言葉、または明示的なサブコマンドで発火する。

"decision"「決定」 "checkpoint"「チェックポイント」 "next task"「次のタスク」 "Phase"「Phase」 "jot this down"「メモして」 "turn into knowledge"「ナレッジにして」 "it's a mess"「散らかってる」 "health check"「健康診断」 searching stored context → search格納済みの検索 → search external research → research外部調査 → research session-state save → save-checkpointセッション保存 → save-checkpoint
03

How to use使い方

$ /ai-context bootstrap # register or create a store, migrate the provisional local $ /ai-context memo この会話の要点 # save the conversation summary as a [Memo] document $ /ai-context knowledge list # list knowledge drafts waiting for promotion

Natural language routes the same way: "continue" / "next task" → next; "organize the docs" → sort project; "save as a lesson" → knowledge; "pin local" → local.

自然文でも同じルーティングになる：「続き」「次のタスク」→ next、「ドキュメント整理」→ sort project、「教訓として残して」→ knowledge、「ローカル固定」→ local。
