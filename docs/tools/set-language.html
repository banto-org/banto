set-language — Switch Banto between Japanese and English, stickilyset-language — 日本語と英語を切替、選択は永続

Banto ships JA-canonical skills plus an auto-generated EN set. set-language makes one of them active, writes the preference to user scope so it survives every future plugin update, and re-materializes it automatically after each update — the only thing left to the user is one restart.

Banto は日本語を正本とする skill 一式と、自動生成した英語版一式の両方を同梱する。set-language はどちらかを有効化し、選択をユーザースコープへ書き込むため、以後のプラグイン更新をまたいで保持される。更新後は同じ言語が自動で再展開されるため、ユーザーに残る作業は再起動のみ。

1

What it does何をするか

This is the one deliberately bilingual skill in Banto — it must be discoverable in either language, so a user on the EN set can switch to JA and vice versa. Running it writes the preference to ~/.claude/banto-language, copies i18n/<lang>/{skills,agents} onto the active skills/ and agents/, stamps the version, and syncs the JA-specific writing-ja rule (deployed for Japanese, removed for English).

Banto の中で唯一、意図的に日英両対応にした skill。EN 版を使っている人が JA へ切り替え、その逆もできるよう、どちらの言語でも発見できる必要がある。実行すると、選択を ~/.claude/banto-language に書き込み、i18n/<lang>/{skills,agents} を有効な skills/・agents/ へコピーし、バージョンを刻印し、日本語専用の writing-ja ルールを同期する（日本語なら配備、英語なら削除）。
