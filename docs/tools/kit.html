kit — The full feature catalog, one natural-language question awaykit — 一言で開ける全機能カタログ

kit prints every command, natural-language trigger, custom agent, and user rule banto ships, exactly as written — no summarizing, no editing. It exists so a user never has to memorize which command does what: asking "what can banto do" surfaces the same catalog a person reading the source would see.

kit は banto が持つ全コマンド・自然文トリガー・カスタムエージェント・ユーザールールを、書かれたまま（要約も編集もせず）表示する。「banto で何ができる」と聞くだけで、ソースを直接読んだときと同じカタログが見える。ユーザーがどのコマンドが何をするか覚える必要をなくすための skill。

1

What it does何をするか

Displays a static, pre-written catalog covering: commands grouped by search/research, context management, document creation, development flow, and tooling; skills that auto-fire from natural language with their example triggers; the 6 custom agents and their invocation paths; the subagent-delegation rubric (when to hand work to Explore, general-purpose, research-agent, architect, debugger, or qa-tester instead of doing it inline); and the user-scope global rules. Nothing here is computed — it is the same reference every time.

静的な事前作成カタログを表示する。内容は、検索・リサーチ / コンテキスト管理 / ドキュメント作成 / 開発フロー / ツール群でグルーピングしたコマンド、自然文から自動発火する skill とその例トリガー、6 つのカスタムエージェントと起動経路、subagent 委譲ルーブリック（Explore・general-purpose・research-agent・architect・debugger・qa-tester のどれに任せるか）、そしてユーザースコープのグローバルルール。ここに計算はなく、毎回同じ参照が返る。
