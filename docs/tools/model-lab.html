model-lab — train models · verify · papermodel-lab — モデル学習 · 検証 · 論文

model-lab is the research-layer sibling of dev-loop and ai-build: pretraining, full fine-tune, PEFT/LoRA, distillation, pruning, and architecture search, run through a verification-centric autopilot all the way to a paper, a Hugging Face model card, and a GitHub release.

model-lab は dev-loop / ai-build の研究層の兄弟。事前学習・フル fine-tune・PEFT / LoRA・蒸留・pruning・アーキ探索を、検証中心の自走で回し、論文 + Hugging Face model card + GitHub 公開まで一貫させる。

01

What it does何をするか

A thin verification spine, not a training framework学習フレームワークではなく薄い検証スパイン

Training delegates to Unsloth / Axolotl / TRL / nanotron / Megatron-LM, tracking to ClearML, config to Hydra, data versioning to DVC, eval to lm-evaluation-harness / lighteval. model-lab supplies only the deterministic gates for reproducibility, evidence, and cost — plus the orchestration between them.

学習は Unsloth / Axolotl / TRL / nanotron / Megatron-LM、追跡は ClearML、設定は Hydra、データ版は DVC、eval は lm-evaluation-harness / lighteval に委譲する。model-lab が持つのは、再現性・裏づけ・コストの決定論ゲートとオーケストレーションのみ。

Statistical rigor is mandatory統計的厳密性を必須化

≥3 seeds (5–10 recommended), BCa bootstrap 95% CI, and a permutation test back every claim. A "no degradation" claim resting on perplexity alone is forbidden — compression methods are checked on reasoning, multilingual, IFEval, and latency together.

≥3 seed（推奨 5–10）+ BCa bootstrap 95%CI + permutation test で主張を裏づける。perplexity 単体での「劣化なし」主張は禁止。圧縮手法は推論・多言語・IFEval・レイテンシを多軸で確認する。
