webread — full text, no summarywebread — 要約なし全文取得

A utility skill that replaces WebFetch. WebFetch hands the fetched page to a small model for summarization, so the main model never reads the raw body and can silently lose critical details. webread extracts the full text locally with trafilatura — no LLM in the loop — and the main model reads it directly.

WebFetch の代替となる utility skill。WebFetch は取得したページを小型モデルに要約させるため、本体モデルが生の本文を一度も読まず、重要な詳細を気づかず落とすことがある。webread はローカルの trafilatura（LLM 不使用）で全文を抽出し、本体モデルが直接それを読む。

01

What it does何をするか

Static-page fetch, full text. Runs webread.sh <URL>, extracts the article body with trafilatura, and returns clean Markdown that the main model reads in full — never a summary standing in for the source.

静的ページの全文取得。webread.sh <URL> を実行し、trafilatura で本文を抽出したクリーンな Markdown を返す。本体モデルが全文を読み、要約が原文の代わりになることはない。

SPA fallback. When trafilatura can't extract a body from a JS-rendered page, it falls back to a 2-step path: render via Claude in Chrome or Playwright, save the HTML, then run webread.sh --html on the saved file.

SPA フォールバック。JS レンダリングのページで trafilatura が本文を抽出できない場合は、Claude in Chrome か Playwright でレンダリング後の HTML を保存し、webread.sh --html で本文を抽出する 2 段階に切り替える。

02

When it firesいつ動くか

a URL with "read this"URL とともに「読んで」 "check the contents"「中身見て」 "summarize this"「要約して」 close-reading a doc/article/blog/GitHub pageドキュメント・記事・ブログ・GitHub ページの精読 searching for a URL → WebSearch / researchURL を探す → WebSearch / research a local file → Read directlyローカルファイル → 直接 Read a direct .md link → Read/curl, not WebFetch.md への直接リンク → Read/curl（WebFetch ではない）
03

How to use使い方

$ /webread https://example.com/release-notes # fetch, extract full text with trafilatura, Read the whole body $ sh "$CLAUDE_PLUGIN_ROOT/scripts/webread.sh" --html saved.html # fallback path: extract from an already-rendered HTML file

"read this page and check the actual contents" with a URL fires the same procedure.

URL とともに「このページを読んで中身を確認して」でも同じ手順が動く。
