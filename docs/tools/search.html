search — internal search, no websearch — 内部検索（web なし）

Searches what Banto already knows: design decisions, docs, and conversation history under the ai-context base. It never touches the web — that job belongs to research. The rule of thumb: already have it → search, don't have it → research.

Banto がすでに持っている情報 — ai-context ベース配下の設計決定・ドキュメント・会話履歴 — を検索する。web には一切触れない。それは research の役目。覚え方は単純：すでに持っている → search、持っていない → research。

01

What it does何をするか

Tiered query expansion. A query is expanded into three weighted groups — Tier1 synonyms & translations (×1.0), Tier2 near concepts (×0.6), Tier3 adjacent concepts (×0.3) — then scored by a ranking script against {base}/decisions/ and {base}/docs/.

3 層のクエリ展開。クエリを重み付き 3 グループ — Tier1 同義語・英訳（×1.0）、Tier2 近接概念（×0.6）、Tier3 隣接概念（×0.3）— に展開し、{base}/decisions/ と {base}/docs/ をランキングスクリプトで採点する。

When the fast path finds nothing, it escalates to a deep path: 3–5 search-agent instances (haiku) run in parallel across Japanese spelling variants, English/code terms, cross-store, and conversation history. A successful deep search appends the winning expansion to search-lexicon.md, so the next fast search is smarter.

fast パスで見つからない場合は deep パスへ進む：日本語表記ゆれ・英語/コード用語・cross-store・会話履歴の 4 役に search-agent（haiku）を 3〜5 体並列起動する。deep が成功すると効いた展開を search-lexicon.md へ追記し、次の fast 検索が賢くなる。

02

When it firesいつ動くか

"we discussed this before"「前に話した」 "recall"「思い出して」 "past chats"「過去のチャット」 "how did this come about"「経緯」 "what did we decide before"「前に決めた」 fetching new external info → research新しい外部情報の取得 → research
03

How to use使い方

$ /search なぜ認証方式を OAuth にしたか # tier-expand the query, rank, Read-verify the top hits $ /search drift detection across projects # cross-project intent → queries the cross-store FTS5 index first

Natural phrasing works too: "remind me why we dropped the old API" fires the same procedure.

自然文でも同じ：「前に決めた話を思い出して」で同じ手順が動く。
