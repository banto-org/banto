AI-Context-StoreAI コンテキストストア

Knowledge that survives the session. セッションを越えて生き残る知識。

Every decision, research note, task, and checkpoint lives in a central store outside your repo. Banto injects it at the start of every session and harvests it at the end — so a /clear or a compaction never costs you the thread. Your code stays clean; the knowledge accrues.

決定・リサーチ・タスク・チェックポイントは、すべて repo の外の中央ストアに置く。 Banto がセッション開始時に注入し、終了時に収穫する — /clear や compaction で文脈を失わない。 コードは綺麗なまま、知識だけが積もる。

Every session writes down; the next reads up.どのセッションも書き下ろし、次が読み上げる。

01

What lives in the storeストアの中身

One folder per project, with a fixed layout — readable as a contract by any tool. Shared knowledge is flat and author-tagged; personal state is namespaced under the author.プロジェクトごとに 1 フォルダ・固定レイアウト — どのツールも契約として読める。共有知識はフラットで author 帰属、個人状態は author 名前空間で分離。

~/ai-context-store/<project>/ ├─ decisions/ # design-decision log shared ├─ docs/ │ ├─ research/ # external findings shared │ └─ knowledges/ # promoted knowledge shared ├─ sessions/ # checkpoints personal ├─ workspaces/ │ └─ <author>/ # per-workspace state personal ├─ learnings/ │ └─ <author>/ # personal lessons personal └─ meta/ # store operation notes
~/ai-context-store/<project>/ ├─ decisions/ # 設計判断ログ 共有 ├─ docs/ │ ├─ research/ # 外部調査 共有 │ └─ knowledges/ # 昇格ナレッジ 共有 ├─ sessions/ # チェックポイント 個人 ├─ workspaces/ │ └─ <author>/ # WS 単位の作業状態 個人 ├─ learnings/ │ └─ <author>/ # 個人の教訓 個人 └─ meta/ # ストア運用メモ
sharedflat, author-tagged (…_<github>.md) — a team shares decisionsフラット・author 帰属（…_<github>.md）— チームで決定を共有 personalunder <author>/ — working state never collides<author>/ 配下 — 作業状態が衝突しない
02

What the plugin does with itplugin がそれで何をするか

The store is not a passive folder. The ai-context skill captures, navigates, and maintains it — reachable by intent, never by memorizing commands.ストアは受け身のフォルダではない。ai-context skill が記録・案内・保守する — コマンド暗記でなくインテントで到達する。

captureRecord記録

  • memo · capture a note into the storeメモをストアへ
  • knowledge · promote a draft to durable knowledge下書きを恒久ナレッジへ昇格
  • decisions are auto-numbered and saved決定は自動採番して保存

navigateDrive前進

  • next · advance to the next open task次の未完タスクへ
  • phase-done · close a phase, auto-archivePhase 完了・自動アーカイブ
  • sort · route a stray doc to its home散らかった doc を振り分け

maintainKeep healthy健全に保つ

  • doctor · lint broken links / orphans / stale decisions (detect only)壊れリンク / orphan / 古い決定を診断（検出のみ）
  • bootstrap · back the store with a GitHub repoGitHub repo でストアを裏づけ
  • local · pin a project local-onlyプロジェクトをローカル固定
番
Never blocks. An unregistered project lands immediately in a temporary local store (~/ai-context-local/<project>/, same layout) — work is never gated on setup. bootstrap later registers or creates a private GitHub store and migrates the local one in (additive, never overwrites).決して止めない。未登録のプロジェクトはまず仮ローカルストア（~/ai-context-local/<project>/・同レイアウト）に着地する — 準備で作業を止めない。bootstrap が後から private な GitHub ストアを登録 / 作成し、ローカル分を取り込む（追加のみ・上書きしない）。
03

How it wires into Claude CodeClaude Code への食い込み方

Banto hooks every stage of Claude Code's lifecycle. The store is fed in, guarded, and harvested automatically — the human never calls it.Banto は Claude Code のライフサイクル各段に hook を張る。ストアは自動で注入・防御・収穫される — 人間は呼ばない。

SessionStart
Inject the store + restore contextストア注入 + 文脈復元
The absolute store path, the latest checkpoint, today's decisions, and the active workspace are injected. Drafts past a threshold prompt a promote-or-delete review.ストアの絶対パス・直近チェックポイント・本日の決定・現ワークスペースを注入。下書きが閾値を超えると昇格 / 削除レビューを提示。
UserPromptSubmit
Nudge to capture記録のうながし
Reminds you where decisions are saved, and recommends a checkpoint as a phase wraps up.決定の保存先を提示し、Phase の区切りでチェックポイントを推奨。
PreToolUse
Guard before the action runs実行前に防御
Deterministic safety valves fire before a tool runs: egress-guard (internal names / PII leaking to a client path), safety-guard (risky shell), odd-kill-switch (direct push to main).tool 実行の前に決定論的な安全弁が発火：egress-guard（内部名 / PII の client パス流出）・safety-guard（危険シェル）・odd-kill-switch（main 直 push）。
PostToolUse
Number decisions, rebuild search決定採番・検索層再生成
A write into decisions//docs/ regenerates the combined search corpus (milliseconds, no model) so internal search always sees the latest.decisions/・docs/ への書き込みで連結検索コーパスを再生成（ミリ秒・モデル不要）。内部検索が常に最新を見る。
PreCompact
Snapshot before context is squeezed圧縮の前に要約保存
A checkpoint is written to sessions/ and the store is synced — so a compaction never costs you the thread.チェックポイントを sessions/ に書き、ストアを同期 — compaction で文脈を失わない。
Stop
Verify before claiming, then learn断定前に検証・そして学習
verify-claim-guard blocks a "done" claim while verification is red; a self-improvement loop captures a learning draft for later review.verify-claim-guard が検証 red のままの「完了」をブロック。自己改善ループが教訓の下書きを残す。

Enforcement is hooks, never promises — the same principle across the whole harness.強制は約束ではなく hook — ハーネス全体を貫く原則。

The harness holds the knowledge. You hold the vision.知識はハーネスが持つ。方針はあなたが持つ。
